# Official feasibility audit — 2026-10-11

All links below are first-party documentation or official source. Installed local evidence is separate from supported claims.

| Area | Verified capability / limitation | Primary source |
|---|---|---|
| Flutter | Linux stable 3.47.7 / Dart 3.13.5 downloaded using official release metadata and SHA256, actually used for analysis/widgets. Per-project pin required; Shorebird availability of that pin must be confirmed on its CLI. | https://storage.googleapis.com/flutter_infra_release/releases/releases_linux.json ; https://docs.flutter.dev/deployment/android |
| Android identity | Upgrade requires unchanged package, compatible signing and increasing versionCode. Play upload key may differ from installed app signing key. | https://developer.android.com/studio/publish/app-signing ; https://developer.android.com/studio/publish/versioning |
| Installation | PackageInstaller sessions support normal OS confirmation. Unknown-app permission and user action are required where applicable; unmanaged silent installation is not promised. | https://developer.android.com/reference/android/content/pm/PackageInstaller ; https://developer.android.com/reference/android/provider/Settings#ACTION_MANAGE_UNKNOWN_APP_SOURCES |
| Emulator | Headless `-no-window`, graphics software mode, snapshots disabled. KVM acceleration and actual VM access must be measured; no dedicated GPU is required but absence of KVM triggers truthful remote-device fallback. | https://developer.android.com/studio/run/emulator-commandline ; https://developer.android.com/studio/run/emulator-acceleration |
| Instrumentation | AndroidJUnitRunner/ADB instrumentation supported with a real test APK/component, not inferred from installation. Runner requires successful instrumentation test output. | https://developer.android.com/training/testing/instrumented-tests/androidx-test-libraries/runner |
| Shorebird base | Official release supports Android APK artifact and pinned Flutter version. App identity for build/patch comes from local shorebird.yaml; history commands support app-id. Adapter arguments were checked against official CLI source, not fabricated. | https://docs.shorebird.dev/code-push/release/ ; https://github.com/shorebirdtech/shorebird/tree/main/packages/shorebird_cli/lib/src/commands |
| Patches | Explicit base release version, staging track, dry-run compatibility. Native/asset/toolchain differences require full release or manual review; no allow-native/asset-diffs override. | https://docs.shorebird.dev/code-push/patch/ ; https://docs.shorebird.dev/code-push/tracks/ |
| Patch signing | RSA key embedded in base, matching private key for patches. Lost key means distributing a new signed base. Android signing keystore, patch RSA keys and manifest Ed25519 key are three distinct identities. | https://docs.shorebird.dev/code-push/guides/patch-signing/ |
| Runtime | shorebird_code_push 2.0.7 supports current/next patch, availability, track-aware checking/updating and restart-required status. New patch takes effect at supported subsequent startup. | https://pub.dev/documentation/shorebird_code_push/2.0.7/ ; https://docs.shorebird.dev/code-push/update-strategies/ |
| Provider cloud | Self-hosted release API/artifacts; Shorebird's compiler/update cloud remains external. Free: 5,000 monthly patch installs, unlimited apps/releases; Pro $20/month; Business $400/month per pricing read. Actual account, current remaining allowance and overage controls UNKNOWN until operator receipt. No plan purchases or automatic overages performed. | https://shorebird.dev/pricing/ ; https://docs.shorebird.dev/account/billing/ |
| Usage | Official per-app patch-install metrics via documented API, bearer account key only. Observations are not exact billing remaining. | https://docs.shorebird.dev/account/api/ ; https://docs.shorebird.dev/account/account-cli/ |
| Android tooling | Linux commandline tools 15859902 fetched from official download page, SHA256 4e4c464f145a7512b57d088ac6c278c03c9eea610886b35a5e0804e74eedf583. Legacy sdkmanager is deprecated in favor of new Android CLI but remains present in this verified archive; check current installed help before host provisioning. | https://developer.android.com/studio#command-tools ; https://developer.android.com/tools/android |

Shorebird asset patching is not assumed supported. Existing engine/plugin binaries cannot be introduced through a Dart patch. Native metadata changes in this pilot require a new APK base before SDK/OTA activation.

ExecutionKit 4.1's FLOW contract is CLI-first with self-hosted/manual CI and phase-boundary quality. The Work snapshot does not include a runnable local `.executionkit/bin/executionkit`; no ExecutionKit Agentic E2E or Visual OS V2 execution is claimed. Host handoff discovers the actual installed canonical kit and records available capabilities before choosing tests. Flutter widget/golden tests executed here are not real Android screenshots or production acceptance.
