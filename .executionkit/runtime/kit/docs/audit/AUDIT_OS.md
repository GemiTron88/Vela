# Audit OS — AI ExecutionKit repository

**Capability level:** `STANDARD`

Audit is evidence-first and independent from implementation. For the 3.0 release candidate, inspect authority boundaries, self-hosting, Agent routing, State continuity, privacy, localhost-only host messaging, repository/worktree identity, telemetry loss/replay behavior, bootstrap/migration safety, MCP surfaces, CI policy and release evidence.

A static validator PASS proves only the checks it executes. Physical macOS/Windows service behavior, editor activation, network ingestion and premium/product behavior require applicable runtime evidence and must remain UNKNOWN when untested.

Findings that require work are mapped into canonical `TODO.md`; audit reports and PR comments are evidence, never shadow task queues.

## V35 reality audit

Audit must challenge system composition, not sum accepted tasks. At V35 phase/release boundaries inspect the integration contract, complete denominator convergence, shared seams, failure/recovery behavior, candidate lineage and change-impact revalidation. Any material current-candidate gap keeps the canonical gate non-terminal or routes it to revalidation; prior labels such as REAL_PRODUCTION are descriptive only unless backed by trusted collector provenance.
