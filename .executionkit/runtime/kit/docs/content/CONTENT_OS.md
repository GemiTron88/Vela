# Content OS — AI ExecutionKit repository

**Capability level:** `STANDARD`

Documentation, standards, examples, migration guidance, release notes and operator instructions are product content for this repository. Content OS requires them to remain coherent with implemented behavior and current evidence.

Do not publish claims that static files, a stale validation run, an unavailable external control plane, an editor hook, a physical runner or production connectivity has been proven when it has not. Versioned docs must distinguish released behavior from 3.0 release-candidate behavior until promotion is complete.

`STANDARD.md` is normative; `README.md` is the entry surface; `PLAYBOOK.md` is the operator runbook; architecture documents define specialized contracts; `CHANGELOG.md` records released change history. Content changes never create a second backlog.
