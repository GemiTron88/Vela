# Skill — Web Components & Frontend Architecture

1. Follow `design-system → component-system → premium-experience` and expose styling via CSS custom properties and `::part()` tokens.
2. Ensure custom elements clean up listeners/observers in `disconnectedCallback`, reflect accessible ARIA roles/states, support keyboard and form-associated internals, and emit typed custom events.
3. Verify with `executionkit guard ux|assets|perf .` and targeted component/browser tests (`executionkit test task . --target <file>`).
