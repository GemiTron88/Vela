# SEO Surface Contract

A Search Surface Contract describes one stable page/route family in `executionkit.seo.json`; it is not a task list.

Required semantics for an indexable family:

- stable `SEO-SURFACE-*` ID and route pattern;
- surface type and primary search intent;
- represented entities/topics as applicable;
- explicit index and canonical policy;
- distinct required visible value;
- representative verification samples;
- internal-discovery requirements where applicable;
- empty/deleted/low-inventory behavior;
- specialized programmatic/local/commerce/international policy where applicable.

Generated/indexable programmatic families require explicit coverage thresholds and the global fail-closed programmatic policy. Contract gaps that require work map to canonical TODO IDs; status never lives in this contract.
