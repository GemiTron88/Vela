# Skill — Independent SEO Audit

1. Reconstruct the public organic-search route denominator from live routes and views, and run `executionkit seo validate .`.
2. Verify that `executionkit.seo.json` accurately reflects every public indexable page family without omitting routes or using `NOT_APPLICABLE` on public web products.
3. Confirm S0–S5 gate receipts, JSON-LD schema validity, canonical/hreflang reciprocity, and absence of thin/doorway programmatic pages before release acceptance.
